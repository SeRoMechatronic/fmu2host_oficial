NivelDeposito — Tank Level Controller

Proportional level controller for a liquid storage tank. A first-order filter (tau=2s) conditions the sensor. Feedforward compensates manual valve disturbances.

SignalTypeDescription
sensor_nivelRealInputNormalized level [0,1]
valvula_manualBooleanInputOutlet valve open/closed
bombaRealOutputPump drive [0,1]
alarma_minimoBooleanOutputLevel < 20%
alarma_maximoBooleanOutputLevel > 80%
bomba_activaBooleanOutputPump running
