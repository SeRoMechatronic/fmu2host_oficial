PotVumetro

5-LED VU meter model driven by a single normalized potentiometer input.

Each LED activates when the input crosses its fixed threshold. The model is purely algebraic (zero continuous states) and is fully compliant with FMI 2.0 Model Exchange and fmi-c-embedded.

OutputColorThreshold
led1Greenpot ≥ 0.20
led2Greenpot ≥ 0.40
led3Yellowpot ≥ 0.60
led4Orangepot ≥ 0.80
led5Redpot ≥ 1.00
