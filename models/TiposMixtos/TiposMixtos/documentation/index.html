Information

TiposMixtos — All Four FMI 2.0 Base Types

This model exercises every variable type defined in the FMI 2.0 standard in a single FMU: Real, Integer, Boolean, and String (as parameters).

The model is purely algebraic (zero states, no integration) so that every output can be verified by hand inspection.
