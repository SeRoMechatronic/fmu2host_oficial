SistemaLorenz — Lorenz Chaotic Attractor

The Lorenz system is the canonical test for numerical integration quality. With the classical parameters (σ=10, ρ=28, β=8/3), the trajectory orbits the butterfly attractor indefinitely.

Integration sensitivity

  • Euler (h=0.01): trajectory escapes attractor before t=5 s. on_attractor becomes FALSE.
  • RK4 (h=0.01): trajectory stays bounded for 50+ seconds. on_attractor stays TRUE.

Attractor bounds

x ∈ [-25,25], y ∈ [-30,30], z ∈ [0,50] (approximate)
