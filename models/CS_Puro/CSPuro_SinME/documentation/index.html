CSPuro_SinME — Purely Algebraic Co-Simulation FMU

This model contains no continuous states and no differential equations. It is designed to exercise the Co-Simulation code path (doStep loop) of a code generation tool, which is structurally different from the Model Exchange path.

When there is nothing to integrate, the codegen must still produce a coherent doStep() body that simply evaluates algebraic expressions and updates outputs.
