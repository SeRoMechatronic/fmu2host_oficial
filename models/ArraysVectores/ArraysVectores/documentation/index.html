ArraysVectores — Fixed-Size Arrays of All Types

This model declares input and output arrays of size N=4 for Real, Integer, and Boolean types. In FMI 2.0, arrays are represented as N individual scalar variables in the modelDescription.xml.

The codegen must unroll each array into N separate fmi2Set*/fmi2Get* calls using the correct index notation (v_real[1] .. v_real[4]).
