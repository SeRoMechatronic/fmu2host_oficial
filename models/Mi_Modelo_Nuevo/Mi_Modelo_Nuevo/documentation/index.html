Mi_Modelo_Nuevo — Name Hyphen Stress Test

This model's name contains hyphens (Mi-Modelo-Nuevo) and mixed case. It tests whether the codegen tool correctly handles the FMI ModelIdentifier when it contains characters that are invalid in C identifiers (hyphens).

Test variants

  • Save as Mi_Modelo_Nuevo.mo (underscores) — must work
  • Save as Mi-Modelo-Nuevo.mo (hyphens in filename) — may break CMake

The model dynamics

First-order low-pass filter: τ·x' = u - x (or -x when inactive). Time constant τ=1 s. Output reaches 63% of input in 1 s, 99% in ~5 s.
