SinInputs — Autonomous Mass-Spring-Damper

This model has zero input variables. It is designed to verify that a codegen tool generates coherent main.c code when there is nothing to set via fmi2SetReal in the step loop.

Physics

m·x'' + c·x' + k·x = 0 with x(0)=1.0, x'(0)=0.0

Default parameters: m=1.5 kg, c=0.3 N·s/m, k=10.0 N/m

Natural frequency: ω₀ = √(k/m) ≈ 2.58 rad/s ≈ 0.41 Hz

The energia output decays monotonically due to damping and can be used to verify correct integration.
