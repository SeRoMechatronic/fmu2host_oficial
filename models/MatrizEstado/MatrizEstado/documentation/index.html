MatrizEstado — LTI State-Space System with 3×3 Matrix

Implements dx/dt = A·x + B·u with A = diag(1,2,3) and B=[1;1;1].

This model tests matrix parameter unrolling (9+3=12 scalar FMI parameters), vector state outputs (3 scalars), and matrix-vector multiply in the ODE.

Key property

With all eigenvalues positive, the system is unstable and states grow exponentially. Analytical solution with u=1: xᵢ(t) = (eˡⁱᵗ - 1)/λᵢ

traza = A[1,1]+A[2,2]+A[3,3] = 1+2+3 = 6.0 (constant at all times)
