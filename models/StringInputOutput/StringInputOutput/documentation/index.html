StringInputOutput — String variables as FMI 2.0 I/O

This model exercises String as runtime input and output, not just as parameters. This forces the codegen to generate fmi2SetString call sites (for inputs) and fmi2GetString call sites (for outputs), which are structurally different from the Real/Integer/Boolean paths.
