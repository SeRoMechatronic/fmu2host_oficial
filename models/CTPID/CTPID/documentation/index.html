CTPID — Temperature PID Controller

Continuous PID controller that regulates temperature using a fan. Both the sensor and setpoint are normalized inputs [0,1] that are mapped to a physical range [T_min, T_max].

Inputs

  • temperatura: normalized sensor reading [0,1]
  • consigna: normalized setpoint from potentiometer [0,1]

Outputs

  • ventilador: fan drive [0,1]
  • ledPorEncima: setpoint above temperature (heating needed)
  • ledPorDebajo: setpoint below temperature (cooling needed)
  • ledAlcanzado: within epsilon dead-band
