=====
  CodigoErrorDiagnostico — Documentation and CI/CD Test Battery
================================================================================

MODEL OVERVIEW
--------------
Purely algebraic. Zero states. Priority cascade: temperatura > tension > vibracion.
Only one error code active at a time (highest priority wins).

INPUTS
------
  temperatura  Real [0,1]   Temperature channel.
  tension      Real [0,1]   Supply voltage channel.
  vibracion    Real [0,1]   Vibration channel.

OUTPUTS
-------
  codigo_error      Integer   0, 101, 202, or 303.
  nivel_prioridad   Integer   0, 1, 2, or 3.
  parada_emergencia Boolean   nivel_prioridad >= 3.
  factor_reduccion  Real      1.0, 0.75, 0.5, or 0.0.

THRESHOLDS
----------
  temperatura > 0.85 → error 101 (priority 3)
  tension     < 0.10 → error 202 (priority 2)
  vibracion   > 0.75 → error 303 (priority 1)

TC-CED-005   Voltage at threshold — no fault
