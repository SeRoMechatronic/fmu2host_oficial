  NivelDeposito — Documentation and CI/CD Test Battery
================================================================================

MODEL OVERVIEW
--------------
NivelDeposito is a tank level controller with one continuous state
(nivel_filtrado). It uses a first-order low-pass filter (tau=2s) on the
sensor, a proportional controller (gain=2.0) targeting 50% fill level, and
feedforward compensation when a manual valve is open.

The model is compliant with FMI 2.0 Model Exchange.

INPUTS
------
  sensor_nivel    Real [0.0, 1.0]   Normalized raw level sensor.
                                     0.0 = empty, 0.5 = half, 1.0 = full.
  valvula_manual  Boolean           Manual outlet valve.
                                     false = closed (no flow), true = open.

OUTPUTS
-------
  bomba           Real [0.0, 1.0]   Pump drive signal.
  alarma_minimo   Boolean           nivel_filtrado < 0.20
  alarma_maximo   Boolean           nivel_filtrado > 0.80
  bomba_activa    Boolean           bomba > 0.05

INTERNAL LOGIC
--------------
  der(nivel_filtrado) = (sensor_nivel - nivel_filtrado) / 2.0
  error_nivel         = 0.5 - nivel_filtrado
  Q_salida            = if valvula_manual then 0.3 else 0.0
  bomba               = clamp(0.5 + 2.0*error_nivel - Q_salida/0.5, 0.0, 1.0)

FILTER NOTE
-----------
Because nivel_filtrado is a state (has a derivative), the output bomba does
NOT respond instantly to sensor_nivel changes. Algebraic checks (t=0)
assume nivel_filtrado starts at its initial value of 0.5 unless otherwise
noted.

PARAMETERS
----------
  nivel_min   = 0.2    Low alarm threshold
  nivel_max   = 0.8    High alarm threshold
  area        = 1.0    Tank area (m²)
  Q_bomba_max = 0.5    Max pump flow (m³/s)
  Q_valvula   = 0.3    Valve outlet flow (m³/s)

================================================================================
  CI/CD TEST BATTERY
================================================================================

--------------------------------------------------------------------------------
TC-ND-001   Steady state at setpoint — valve closed
--------------------------------------------------------------------------------
  Initial state:  nivel_filtrado = 0.5
  Inputs:         sensor_nivel=0.50, valvula_manual=false
  Simulation:     t=0 (algebraic)
  Expected:
    error_nivel  = 0.0
    bomba        = clamp(0.5 + 0.0 - 0.0, 0, 1) = 0.50
    alarma_minimo = false
    alarma_maximo = false
    bomba_activa  = true  (0.50 > 0.05)
  Purpose: Verify nominal steady-state operating point.

--------------------------------------------------------------------------------
TC-ND-002   Level at minimum alarm threshold
--------------------------------------------------------------------------------
  Initial state:  nivel_filtrado = 0.20
  Inputs:         sensor_nivel=0.20, valvula_manual=false
  Simulation:     t=0
  Expected:
    alarma_minimo = false  (0.20 is NOT < 0.20, boundary is exclusive)
    alarma_maximo = false
    bomba         = clamp(0.5 + 2*0.3, 0, 1) = clamp(1.1, 0, 1) = 1.0
    bomba_activa  = true
  Purpose: Verify boundary condition — alarm uses strict < operator.

--------------------------------------------------------------------------------
TC-ND-003   Level just below minimum alarm threshold
--------------------------------------------------------------------------------
  Initial state:  nivel_filtrado = 0.199
  Inputs:         sensor_nivel=0.199, valvula_manual=false
  Simulation:     t=0
  Expected:
    alarma_minimo = true   (0.199 < 0.20)
    alarma_maximo = false
    bomba         = 1.0    (high demand, clamped)
    bomba_activa  = true
  Purpose: Verify alarm activates just below threshold.

--------------------------------------------------------------------------------
TC-ND-004   Level at maximum alarm threshold
--------------------------------------------------------------------------------
  Initial state:  nivel_filtrado = 0.80
  Inputs:         sensor_nivel=0.80, valvula_manual=false
  Simulation:     t=0
  Expected:
    alarma_minimo = false
    alarma_maximo = false  (0.80 is NOT > 0.80, boundary is exclusive)
    bomba         = clamp(0.5 + 2*(0.5-0.8), 0, 1) = clamp(-0.1, 0, 1) = 0.0
    bomba_activa  = false
  Purpose: Verify upper boundary condition.

--------------------------------------------------------------------------------
TC-ND-005   Level just above maximum alarm threshold
--------------------------------------------------------------------------------
  Initial state:  nivel_filtrado = 0.801
  Inputs:         sensor_nivel=0.801, valvula_manual=false
  Simulation:     t=0
  Expected:
    alarma_maximo = true
    bomba         = 0.0    (negative error → pump off)
    bomba_activa  = false
  Purpose: Verify high alarm activates just above threshold.

--------------------------------------------------------------------------------
TC-ND-006   Manual valve open — feedforward compensation
--------------------------------------------------------------------------------
  Initial state:  nivel_filtrado = 0.5
  Inputs:         sensor_nivel=0.50, valvula_manual=true
  Simulation:     t=0
  Expected:
    Q_salida      = 0.3
    bomba         = clamp(0.5 + 0.0 - 0.3/0.5, 0, 1)
                  = clamp(0.5 - 0.6, 0, 1) = 0.0
  Note:           Feedforward actually reduces pump here because Q_salida/Q_max
                  = 0.6 > 0.5 baseline. This is correct behavior showing the
                  feedforward term dominates at setpoint.
  Purpose: Verify feedforward term activates when valve is opened.

--------------------------------------------------------------------------------
TC-ND-007   Low level with valve open — maximum pump demand
--------------------------------------------------------------------------------
  Initial state:  nivel_filtrado = 0.30
  Inputs:         sensor_nivel=0.30, valvula_manual=true
  Simulation:     t=0
  Expected:
    error_nivel   = 0.20
    bomba         = clamp(0.5 + 2*0.2 - 0.6, 0, 1) = clamp(0.3, 0, 1) = 0.30
    alarma_minimo = false  (0.30 > 0.20)
    bomba_activa  = true
  Purpose: Verify combined P-control and feedforward under concurrent stress.

--------------------------------------------------------------------------------

  Initial state:  nivel_filtrado = 0.0

  Simulation:     t=0
  Expected:
    alarma_minimo = true
    bomba         = 1.0    (maximum demand)
    bomba_activa  = true
  Purpose: Verify behavior at absolute minimum (empty tank).

--------------------------------------------------------------------------------
TC-ND-009   Tank full

  Initial state:  nivel_filtrado = 1.0
  Inputs:         sensor_nivel=1.0, valvula_manual=false
  Simulation:     t=0
  Expected:
    alarma_maximo = true
    bomba         = 0.0    (pump off — level above setpoint)
    bomba_activa  = false
  Purpose: Verify behavior at absolute maximum (full tank).

--------------------------------------------------------------------------------
TC-ND-010   Filter transient — step from 0.5 to 0.2 in sensor
--------------------------------------------------------------------------------
  Scenario:
    Initial state:  nivel_filtrado = 0.5
    t=0..2:         sensor_nivel=0.50, valvula_manual=false
    t=2+:           sensor_nivel=0.20, valvula_manual=false
  Sample at t=4 (2 seconds after step, 1 time constant elapsed):
    Expected: nivel_filtrado ≈ 0.5 + (0.2-0.5)*(1-e^-1) ≈ 0.31
    alarma_minimo = false  (0.31 > 0.20)
    bomba > 0.5    (error is positive)
  Purpose: Verify first-order filter dynamics after a step disturbance.
